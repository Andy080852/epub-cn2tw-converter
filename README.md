# EPUB 簡轉繁工具

一個純前端的 EPUB 簡體轉繁體工具,支援台灣/香港用字與慣用詞轉換,
所有處理都在瀏覽器本機完成,不會上傳任何檔案。

## 功能
- 支援台灣用字+慣用詞 / 香港用字+慣用詞等多種模式
- 自訂詞彙表,可針對特定用語二次修正
- 拖曳上傳,操作簡單
